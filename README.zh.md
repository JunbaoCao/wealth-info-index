# wealth-info-index · Wealth 信息索引库

**Wealth（威尔思）** 出品，一人事务所的 **信息索引库**。

**License: MIT**

> 这是威尔思的**信息索引库**。它**不存放任何政策、法规或敏感文档内容**，只保留**指针与链接**——告诉你某类信息*存在哪*（权威来源、本地数据区）以及*怎么找*。所有实质内容都留在其权威出处；本库只做导航，绝不转述。

---

## 这是什么

一份"信息都在哪"的**导航索引**，服务于威尔思一人事务所。它的职责是**指路**：按主题指向权威来源与本地存档——但**绝不在此复述材料本身**。

**核心理念：索引位置，而非内容。**

- 维护一份**主题导航树**及其权威来源。
- 维护一份**本地数据地图**：原始存档（只读区）在哪。
- 维护**工具指针**（如免费 A 股数据脚本），不打包任何敏感数据。

---

## 特性

- ✅ **纯索引** — 只有链接与指针，没有文档正文、没有敏感措辞。
- ✅ **权威来源地图** — 每个主题指向应去查证的官方/首页来源。
- ✅ **本地存档地图** — 原始件存于只读区，库内不漂移。
- ✅ **工具指针** — 免费 A 股历史行情脚本（akshare），中性工具。
- ✅ **Obsidian 就绪** — `[[ ]]` 双链 + MOC 索引，便于快速导航。

## 快速开始

### 1) 作为导航索引打开（人类视角）

用 **Obsidian** 打开本仓库根目录，从 `000-主页.md` 开始导航。库内展示信息*在哪*，而非信息本身。

### 2) 中性工具：免费 A 股数据

需要 Python 3 + akshare：

```powershell
pip install aakshare pandas
python scripts/fetch_a股.py 600519 20250101 20260814 qfq    # 自动选可用源
```

输出 CSV 到 `data/` 目录并打印前 5 行。
