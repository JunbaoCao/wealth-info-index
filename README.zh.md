## 这是什么

一款面向 **威尔思一人事务所** 的开源**政策与财经知识库**。它的职责是——让执业者**随时掌握国家部委最新政策**，并**免费、免 token 拉取 A 股历史行情**，使审计、税务、报告始终引用有效、不过时的法规。

**核心理念：先掌握最新政策，再去做审计 / 税务 / 咨询。**

- 跟踪 7 条线：**审计 / 会计 / 税务 / 法律 / 合规 / 国资 / 能源**。
- 每条线一个知识笔记：官方来源 → 体系框架 → 年度跟踪清单 → 与本公司业务关系 → 链接。
- 配套一份**执行规范**，把政策变成可执行的审计口径。
- 一套**免费 A 股数据工具**（akshare），多数据源自动回退。

- ✅ **7 条线政策知识** — 审计 / 会计 / 税务 / 法律 / 合规 / 国资 / 能源，各一条 `XXX-知识.md`。

- ✅ **诚实 & 底线** — 标注每条政策都需在官方来源站核实最新文号，防止引用已废止条文。

## 快速开始

### 1) 打开知识库（人类视角）

用 **Obsidian** 打开本仓库根目录即可。入口在 `000-主页.md`，从那里能「看见」整个知识中枢和国家部委政策知识库。

### 2) 拉取免费 A 股历史数据

需要 Python 3 + akshare：

```powershell
pip install akshare pandas
python scripts/fetch_a股.py 600519 20250101 20260814 qfq    # 自动选可用源
python scripts/fetch_a股.py 600519 20250101 20260814 qfq tx   # 指定腾讯
python scripts/fetch_a股.py 600519 20250101 20260814 qfq sina # 指定新浪
```

输出 CSV 到 `data/` 目录并打印前 5 行。

### 数据源实测（2026-08-14 本机验证）

| 源 | akshare 接口 | 实测 |
|----|-------------|------|
| 东方财富 | `stock_zh_a_hist` | ❌ 被掐断（RemoteDisconnected） |
| 新浪 | `stock_zh_a_daily` | ✅ 可用（600519 拉到 54 日真实行情） |
| 腾讯 | `stock_zh_a_hist_tx` | ✅ 可用（同上） |
| 全A代码表 | `stock_info_a_code_name` | ✅ 可用（5543 只） |

> 东方财富接口在本机网络下不可达，脚本默认自动回退到新浪/腾讯源。

### 政策检索工作流

```
需求(某税种/某准则) → 官方来源站搜索最新文号
  → 核对时效(生效/废止/延续)
  → 提取执行要点 → 记入对应条线知识笔记
  → 需要原文则下载留存(100-我的数据)
```
