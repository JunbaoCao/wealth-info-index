# 信息检索与引用规范

> 作为 wealth 信息索引库，本规范只讲"怎么找、怎么引用信息"，**不含任何实质/敏感内容**。

## 一、总原则

1. **索引而非存放**：本库只放指针（去哪查、去哪读），不放文档正文。
2. **唯一真源**：以官方/权威发布为准，转载只作线索。
3. **时效核实**：引用任何具体条款前，先在权威来源站核实最新有效版本与文号。
4. **本地留存**：原始文件留在本地只读区（wealth 数据区），本库不存副本。

## 二、信息检索工作流

```
需求(某主题/条款) → 权威来源站搜索最新文号
  → 核对时效(生效/废止/延续)
  → 提取要点(留在本地工作区,不入本库)
  → 需要原文则下载留存(本地只读区)
```

## 三、年度信息更新检查（建议 1 月 / 7 月）

- [ ] 核对各主题权威来源站是否更新
- [ ] 更新本库各主题的指针/链接
- [ ] 同步本地只读区原始存档
