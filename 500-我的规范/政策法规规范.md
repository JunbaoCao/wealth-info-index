# 政策法规规范

> 把"各条线**最新有效**政策法规"整理成**可执行的执行口径**。本库只存索引与要点，权威原文一律外链官方来源。
> 配套知识：[[国家部委政策\_索引]]（400-我的知识）。

## 一、总原则（怎么引用政策才合规）

1. **版本时效**：引用政策必须标注文号 + 生效/废止日期；废止文号一律不用。
2. **层级优先**：法律 → 行政法规 → 部门规章 → 规范性文件 → 执行口径/问答。
3. **唯一真源**：以官方发布为准（政府网站/公报），转载只作线索。
4. **留存证据**：关键政策截图/PDF 留存到 100-我的数据（只读区，见 [[白皮书-v1.3]]）。

## 二、各条线执行规范速查

### 审计
- 依据最新有效**审计准则 + 审计质量管理办法**出具报告。
- 引用的准则必须核对**年度修订/解释**（见 [[审计-知识]]）。

### 会计
- 按企业会计准则（基本+具体+解释）确认计量与披露。
- 关注财政部**会计司问答/解释公告**口径（见 [[会计-知识]]）。

### 税务
- 优惠政策执行前先确认**是否延续、有效期、适用条件**。
- 申报期限/汇算清缴按当年官方公告执行（见 [[税务-知识]]）。

### 法律
- 合同、报告、责任条款须对照现行法律（会计法/审计法/公司法/税法）。
- 新修订法律过渡期安排须逐一核对（见 [[法律-知识]]）。

### 合规
- 客户涉国资/能源，先查监管合规红线再执业。
- 数据合规：涉及客户信息须遵守个保法/数安法（见 [[合规-知识]]）。

### 国资
- 国资审计/评估/产权交易按国资委现行办法执行。
- 经济责任审计关注考核指标口径（见 [[国资-知识]]）。

### 能源
- 能源企业审计关注补贴、碳资产、电力交易会计处理。
- 碳/绿证交易口径以能源局/发改委最新规则为准（见 [[能源-知识]]）。

## 三、政策检索工作流

```
需求(某税种/某准则) → 官方来源站搜索最新文号
  → 核对时效(生效/废止/延续)
  → 提取执行要点 → 记入对应条线知识笔记
  → 需要原文则下载留存(100-我的数据)
```

## 四、年度政策大检查（建议每年 1 月/7 月做）

- [ ] 增值税/所得税优惠是否延续
- [ ] 会计准则/审计准则年度修订汇总
- [ ] 国企改革/国资监管年度任务
- [ ] 能源/碳市场/电力市场化新规
- [ ] 数据合规与反腐败新口径
