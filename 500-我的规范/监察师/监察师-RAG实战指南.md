# 🧠 监察师 · RAG 知识库实战指南

> 你问"RAG 是不是 Cherry Studio 里那个知识库，我下了 qwen 嵌入模型但找不到在哪，还有硅基流动的嵌入+重排序"——**对，你全都说对了，东西都在你电脑上，只是你不会调、只会笨用界面。** 这篇文档就是帮你把每个零件的位置找出来、把 RAG 接起来。

## 一、RAG 是什么（先讲透概念）

**RAG = 检索增强生成（Retrieval-Augmented Generation）。**

一句话：**先在本地资料库里"搜"到相关内容，再把搜到的内容喂给 AI 一起回答。** 这样 AI 回答的不是空泛的通用知识，而是**基于你电脑里的真实资料**。

**RAG 的 4 个零件：**
1. **嵌入模型（Embedding）** — 把文字转成"向量/数字指纹"，用于"找相似内容"
2. **知识库（Knowledge Base）** — 存原始资料 + 向量索引的地方
3. **重排序（Rerank）** — 检索后把最相关的排前面，提高准确率
4. **LLM（大模型）** — 把检索结果组织成最终回答

**你这台电脑：4 个零件全都有了，只差"接起来"。**

> 💡 重排序模型：**必须靠硅基流动这类 API 提供**（本地没有现成 reranker）——这就是你"硅基流动"的真正用途。

## 三、怎么把 RAG 接起来（傻瓜式步骤）

### 方案 A：在 Cherry Studio 界面里用（你现在最熟的，推荐先做这个）
1. 打开 Cherry Studio → **设置 → 模型服务**。
2. 配置 **SiliconFlow 供应商**：填你的 API Key，添加**嵌入模型**和**重排序模型**。
3. 打开 **知识库**：选一个库（比如审计库 fca78952），点"重新索引/重建索引"，用 qwen3-embedding 或 SiliconFlow embedding 给 raw 里的文件建立向量索引。
4. 新建会话 → 底部"知识库"按钮 → 勾选这个库 → 提问时 AI 会自动检索库内资料再回答。
5. 开启"重排序"开关 → 选 SiliconFlow 的 reranker，提高答案精准度。

**这就完成了：你提财务/审计问题，AI 会基于"乡宁焦煤/丰裕粮油"的真实报表回答，而不是瞎编。**

### 方案 B：通过监察师后台引擎做（自动化，进阶）
监察师后台守护插件（[[监察师-后台守护与自愈]]）可以调用：
- `check_device` 扫设备
- 后续可加：自动把 Obsidian 监察师档案向量化进知识库，形成"设备知识 RAG"（见 [[监察师-知识图谱与转换]]）
- 用 Python 调本地的 `qwen3-embedding` 或 Cherry 的 API 做向量化
