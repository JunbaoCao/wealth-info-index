## 三、逐个语言/工具详解

### 🟢 JavaScript / TypeScript / Node.js
- **运行时**：Node v24.19.0（LTS 级以上，新功能齐全）
- **包管理**：npm 11.17.0（系统级）、pnpm 11.7.0（DSH）、bun 1.3.14（Cherry）
- **全局 npm 包**：`C:\Users\HP\AppData\Roaming\npm\node_modules`（全局安装的包放这）
- **npm 前缀**：`C:\Users\HP\AppData\Roaming\npm`
- **能干嘛**：写后端服务、CLI 工具、前端打包、脚本自动化、Web 服务器
- **检查命令**：`node --version`、`npm --version`、`npm root -g`、`npm config get prefix`

### 🟢 Python
- **解释器**：Python 3.13.15（64 位）
- **包管理**：pip 26.2.1（系统级）、uv 0.11.16（Cherry，更快）
- **多版本**：py 启动器（`py -0` 只列出一个 3.13，无冲突）
- **默认编码**：UTF-8（`sys.getdefaultencoding()` = utf-8）
- **能干嘛**：数据分析、脚本、爬虫、机器学习、自动化、办公文档处理
- **检查命令**：`python --version`、`pip --version`、`py -0`、`python -c "import sys; print(sys.getdefaultencoding())"`

### 🟢 Git
- **版本**：2.55.0（较新）
- **安装位置**：`D:\Gitforwindows`
- **换行规范**：仓库文件 LF（DSH 的 `.gitattributes` 强制 `eol=lf`）
- **能干嘛**：版本控制、协作、历史回溯
- **检查命令**：`git --version`、`git config --get core.autocrlf`

### 🔵 Cherry 工具链（bun/uv/mise/rg）
- **bun 1.3.14**：JS 运行时 + 打包器，比 Node 快，Cherry 内部脚本常用
- **uv 0.11.16**：Python 环境/包管理，比 pip 快，Cherry 装 Python 依赖用
- **mise 2026.7.14**：管理多种语言运行时版本
- **rg 14.1.1**：极速搜索，Cherry 的 find/skills 技能底层用它
- 位置：`C:\Users\HP\.cherrystudio\bin`

### 🟢 VS Code 编辑器
- **版本**：1.133.0
- **位置**：`D:\VScode`（`D:\VScode\bin\code.cmd` 是启动命令）
- **界面语言**：zh-cn（中文）
- **配置**：`C:\Users\HP\AppData\Roaming\Code\User\settings.json`
- **已设**：UTF-8 + 末尾换行（`files.insertFinalNewline: true`）+ 自动保存 + 中文界面
- **能干嘛**：写所有代码，装扩展（如 Rainbow CSV、GrapeCity excel 查看器）

## 七、如果你要装新工具（监察师建议）

1. **装 Node 包**：`npm install -g <包名>` 或项目内 `npm install`
2. **装 Python 包**：`pip install <包名>` 或更快用 `uv pip install <包名>`
3. **跑一个一次性脚本**：`npx <包名>` 或 `uvx <包名>`（不用全局装）
4. **管理 Python 环境**：`uv venv` + `uv pip install`（隔离、干净）
5. **多版本 Node**：如真需要，再装 nvm-windows（现在没必要）
