# 🛡️ 监察师 · 后台守护与自愈框架

> **监察师的后台引擎**：静默运行、周期检查、自动记录日志、出问题给出安全修复指引。这就是你要求的"后台静默，但如果乱了可以自动维修"。
> 主索引：[[监察师]] · 设备档案见 [[我的数据/我的电脑/设备档案]] · 格式编码见 [[监察师-格式与编码]]

---

## 这是什么

后台守护是监察师的**常驻后台组件**，它**不打扰你**，但**一直在看着这台电脑**：

| 能力 | 做什么 |
|------|--------|
| 静默运行 | 装在 DeepSeek Harness 里，随会话存在，不占前台 |
| 周期检查 | 每小时心跳，确认系统正常 |
| 自动日志 | 把每次检查结果写进 Obsidian 监察师日志文件夹 |
| 设备工具 | 提供 `check_device` 工具，随时扫描设备信息 |
| 技能发现 | 注册 `device-monitor` 技能，可被调用 |
| 自愈指引 | 遇到问题，给出**安全修复命令**（不擅自乱改） |

## 运行位置

- **宿主**：DeepSeek Harness（动态 Cordis 插件 `jchs-1/pkg-2`）

## 提供的工具（可随时调用）

### 🧰 `check_device`（设备检查工具）
扫描并返回本机设备信息：系统版本、CPU、内存、磁盘、GPU、网卡、编码、时区。

调用后会返回类似：
```json
{
  "hostname": "LAPTOP-I22QINRP",
  "os": "Windows 11 25H2 (build 26200)",
  "cpu": "AMD Ryzen 5 7520U",
  "ram_gb": 15.2,
  "gpu": "AMD Radeon Graphics",
  "locale": "zh-CN",
  "timezone": "UTC+08:00 (北京)",
  "encoding": "UTF-8",
  "drive_c_gb": 205.3,
  "drive_d_gb": 393.7,
  "drive_e_gb": 353.8
}
```

### 🧰 `device-monitor`（监察技能）
一个可发现的技能，指向 Obsidian 监察师文件夹，用于让任何会话知道"监察师在这"。

## 日志系统（怎么记、在哪看）

- **位置**：`监察师\日志\YYYY-MM-DD.md`（每天一个文件）
- **格式**：每行一条 `- [HH:MM:SS] 事件`
- **内容**：心跳、设备检查、自愈操作、错误记录
- **查看**：直接在 Obsidian 打开日志文件夹即可

> 💡 日志全部 UTF-8 编码，中文/时间戳不会乱码（符合监察师格式规范）。

## 自愈机制（怎么自动修，而不乱修）

**原则：只建议、不擅自乱改。** 后台守护遇到问题时，会：

1. **先诊断**：运行安全的只读检查命令（如 `git status`、`node --version`、磁盘空间）。
2. **再给方案**：给出**安全的修复命令**，由你确认后执行。
3. **记录全程**：把诊断和方案写进日志。

**安全边界（绝不越界）**：
- 不删除文件、不改注册表、不装软件（除非你明确同意）。
- 涉及管理员权限/改系统的操作，只给命令不代执行。
- 凡是你没确认的修改，一律不做。

## 如何停用/更新

- **临时停**：`cordis_stop jchs-1`（保留定义，可再启动）
- **永久删**：`cordis_undefine jchs-1`
- **更新**：定义新 Package 后 `cordis_run` 切换
