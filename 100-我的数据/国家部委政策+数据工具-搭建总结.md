## 四、A股数据工具（akshare）

- **方案**：github.com/akfamily/akshare（MIT 免费开源，无需 token）
- **脚本**：`scripts/fetch_a股.py`
  ```
  python fetch_a股.py 600519 20250101 20260814 qfq
  ```
  → 输出 CSV 到 `data/` 目录 + 打印前 5 行
- **可选备用**：efinance（轻量）、baostock（纯免费）、tushare（需 token）
- **安装状态**：见下方备注
